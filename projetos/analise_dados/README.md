# Análise de Dados — vendas fictícias

## Objetivo

Criar um projeto de portfólio para praticar limpeza, consulta e interpretação de dados usando Python, SQL e Excel. O conjunto de dados será fictício e não representa uma empresa real.

## Perguntas que o projeto deverá responder

- Qual é o faturamento total por mês?
- Quais categorias têm maior faturamento?
- Qual é o ticket médio por pedido?
- Existem valores ausentes ou registros inconsistentes?

## Plano de trabalho

1. Criar ou importar uma pequena base fictícia.
2. Inspecionar e limpar os dados com Python.
3. Consultar agregações com SQL.
4. Construir tabelas e gráficos no Excel.
5. Documentar conclusões com métricas calculadas, sem inventar resultados.

## Estrutura prevista

- `dados/`: dados sintéticos para exercício.
- `analise.py`: inspeção e análise em Python (a implementar).
- `consultas.sql`: consultas SQL (a implementar).
- `relatorio.md`: resultados e limitações (a criar depois da análise).
