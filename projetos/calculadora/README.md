# Calculadora em Python

Projeto inicial de portfólio para praticar fundamentos da linguagem Python.

## Funcionalidades

- Soma, subtração, multiplicação e divisão.
- Validação de entradas numéricas.
- Tratamento de divisão por zero.
- Repetição de operações até o usuário escolher sair.

## Requisitos

- Python 3.10 ou superior.
- Nenhuma biblioteca externa.

## Como executar

No terminal, dentro desta pasta, execute:

```bash
python calculadora.py
```

Em alguns ambientes Windows, pode ser necessário usar `py calculadora.py`.

## Conceitos praticados

Funções, `while`, `if/elif/else`, `try/except`, conversão de tipos e organização de código.
