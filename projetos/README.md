# Projetos práticos

Esta pasta reúne projetos de aprendizagem que combinam os fundamentos estudados.

## Projetos

1. [Calculadora em Python](./calculadora/): funções, validação e tratamento de erros.
2. [Sistema de controle de ponto](./controle_ponto/): planejamento inicial de registros de jornada e relatórios.
3. [Análise de dados de vendas fictícias](./analise_dados/): projeto planejado para praticar Python, SQL e Excel com dados sintéticos.

Os projetos serão considerados concluídos somente depois de implementados e testados.
